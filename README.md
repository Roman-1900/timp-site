# Timp — лендинг и кабинет клиента (версия C)

Статический сайт: открывается без сборки. Файлы:
- index.html — главная (все стили и скрипты внутри)
- client.html — вкладка «Клиент»: кабинет с сервисами после регистрации (макет), переключатель тёмной и светлой темы (выбор запоминается в браузере)
- favicon.svg, logo.svg — логотип
- robots.txt

## Как выложить
Скопируйте содержимое папки в корень сайта (или в папку лендинга). Шрифты Montserrat и Inter подгружаются с Google Fonts.

## Что нужно донастроить
1. Регистрация по email: в конце index.html в переменной REGISTER_ENDPOINT укажите адрес API (POST, JSON {"email": "..."}). Пока она пуста, форма проверяет адрес и показывает сообщение «Регистрация скоро откроется».
2. Кабинет (client.html) сейчас статичный макет: адрес почты name@example.com — заглушка, кнопки «Открыть» у сервисов ведут на href="#". Нужно подставить данные пользователя из вашей авторизации, закрыть страницу для неавторизованных и вписать реальные адреса сервисов. Список сервисов будет уточнён.
3. QR-код на главной ведёт на https://mytimp.ru. Если нужен другой адрес, QR нужно сгенерировать заново.
4. Кнопки App Store и Google Play, ссылки подвала («О Timp», «Контакты», «Условия» и др.) пока href="#".
5. Переключатель RU / RO пока не работает: румынской версии нет.
